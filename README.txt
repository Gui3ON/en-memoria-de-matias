Página conmemorativa de Matías — Paquete listo para GitHub Pages / servidor
=========================================================================

Contenido del archivo comprimido:
- index.html        Página web completa (con vela interactiva apagada/encendida).
- img/              Carpeta con las 24 imágenes de la página.

Cómo publicarla en GitHub Pages:
1. Descomprime este archivo ZIP.
2. Sube index.html y la carpeta img/ a la raíz de tu repositorio público en GitHub.
3. Ve a Settings -> Pages, elige la rama main y carpeta / (root), y guarda.
